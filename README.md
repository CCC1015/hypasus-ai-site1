# Hypasus AI — Next.js + Tailwind + Framer Motion

A modern, animated agency site scaffold ready for Vercel.

## Quickstart

```bash
pnpm i # or npm i / yarn
pnpm dev # http://localhost:3000
```

## Deploy to Vercel
- Push to GitHub
- Import the repo in Vercel
- Build command: `next build`
- Output: `.next`
- Set your custom domain: hypasus.nl

## Customize
- Replace `/public/logo.svg` with your logo
- Replace `/public/hero-visual.jpg` with your visual
- Edit copy in components (Hero, Services, About, Contact)
